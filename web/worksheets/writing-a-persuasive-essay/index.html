4. What is a claim?
5. What does "rebuttal" mean?
  1. the main argument
  2. person, place, thing, or idea
  3. characters' spoken words

6. A persuasive essay states a clear ______ (thesis) and tries to convince readers.
7. "rebuttal" means facts or examples that support a claim. T   F
8. Write a thesis for: 'Should homework be banned?'
9. What does "claim" mean?
  1. the turning point
  2. action or state of being
  3. person, place, thing, or idea
  4. the main argument
Show the answer key
  1. 1-D, 2-C, 3-B, 4-A
  2. counterclaim
  3. True
  4. The main position the writer argues.
  5. D. a response that disproves a counterclaim
  6. claim
  7. False ("rebuttal" means a response that disproves a counterclaim.)
  8. Answers vary — must take a clear position.
  9. D. the main argument

Key vocabulary

  • claim: the main argument
  • evidence: facts or examples that support a claim
  • counterclaim: an opposing argument
  • rebuttal: a response that disproves a counterclaim
