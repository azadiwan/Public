  1. 1-B, 2-C, 3-D, 4-A
  2. services

  4. Usually a want
  5. C. limited resources and unlimited wants

Key vocabulary

  • scarcity: limited resources and unlimited wants
  • opportunity cost: the value of the next-best choice given up
  • goods: things you can touch that satisfy wants
  • services: work done for others
